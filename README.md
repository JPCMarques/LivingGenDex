# Living Dex Guides (Gen 3–9)

Step-by-step guides and trackers for a legal, non-shiny living dex, Gen 3 to Gen 9. Every form HOME supports is covered, and only base forms are boxed (you evolve them on Switch).

- **Boxes** at the top of every gen page show each slot in 30-slot boxes (sprites load from PokeAPI). Tap a sprite to mark it collected; uncollected slots are greyed out.
- Walkthrough steps get a badge (e.g. 2/6) that turns into a ✓ once every Pokémon the step covers is collected.
- Pick a generation from the dropdown. Links like `#gen5` or `#gen8/tracker` open a specific guide.
- **Guide** tab: the full walkthrough, with time estimates.
- **Tracker** tab: one row per slot. Your ticks are saved in your browser. Use **Progress data → Export/Import** to move them to another device.
- Pokémon names link to their Bulbapedia page (sprites, forms), and locations have a "map ↗" link.

## Publish on GitHub Pages

1. Push these files to the root of the `main` branch.
2. Go to **Settings → Pages**, set **Source: Deploy from a branch**, then pick **Branch: `main`**, folder **`/ (root)`**, and save.
3. The site goes live at `https://<user>.github.io/<repo>/` after a minute or two.
